PriceHub 价格管理工作台 —— Windows 使用说明
==============================================

一、运行环境
  - Windows 10 / 11（64 位）
  - Python 3.10 ~ 3.13（64 位）。没有的话，启动脚本会提示安装方法：
      https://www.python.org/downloads/windows/ 下载 "Windows installer (64-bit)"，
      安装时勾选 "Add python.exe to PATH"。
  - 首次运行需要联网下载依赖（约 80 MB，默认用清华镜像，失败自动改用官方源）。

二、启动
  1. 把压缩包完整解压到一个文件夹（路径里最好不要有空格或特殊符号，例如 D:\PriceHub）。
     不要直接在压缩包里双击运行。
  2. 双击「启动PriceHub.bat」。
     - 第一次会创建虚拟环境 .venv 并安装依赖，需要 1–5 分钟；以后启动只要几秒。
     - 就绪后优先打开独立桌面窗口（标题 PriceHub）；仅当 pywebview/WebView2 不可用时才打开系统浏览器。
  3. 使用期间不要关闭黑色命令行窗口；关闭它就停止 PriceHub。

三、数据
  - 数据保存在 data\pricehub.db（SQLite），压缩包里已带当前数据（42 个商品及其价格历史）。
  - 备份：直接复制 data\pricehub.db；或在界面「设置与集成 → 备份与恢复」下载完整备份。
  - 服务只监听本机 127.0.0.1，局域网其他电脑访问不到。

四、精简版说明（自动降级的功能）
  为了安装包小、安装快，以下大模型/重型组件没有默认安装，相关功能会自动降级，不影响使用：
  - 语义搜索、同款去重的标题相似度：多语言向量模型 → 字符 n-gram（TF-IDF）
  - 以图搜图：CLIP → 感知哈希（phash）
  - 价格预测：Prophet → 统计预测
  - 动态网页采集：无头浏览器 → 直连抓取
  需要完整功能时，可在命令行执行（体积约 1–2 GB）：
    .venv\Scripts\pip install sentence-transformers faiss-cpu playwright prophet -i https://pypi.tuna.tsinghua.edu.cn/simple
    .venv\Scripts\python -m playwright install chromium

五、常见问题
  - 提示“没有找到 Python”：按第一节安装 Python，并勾选 Add to PATH，然后重新双击启动。
  - 提示端口 8800 被占用：说明已有程序占用。若是 PriceHub 已在运行，脚本会直接打开浏览器；
    否则可先执行 set PRICEHUB_PORT=8801 再运行 .venv\Scripts\python run_windows.py。
  - 依赖安装失败：检查网络/代理后重新双击；如要重装，删除 .venv 文件夹后再启动。
  - 杀毒软件拦截：把解压目录加入信任后重试。

六、AI 搜索等需要密钥的功能
  不需要也不要把密钥发给任何人。需要时在界面「设置与集成」里自行填写，或设置对应的环境变量。
