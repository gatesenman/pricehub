# PriceHub 功能缺口分析（v4 → v5）

> 目的：站在使用者角度，对照价格全生命周期 10 个环节与 9 类用户角色，找出缺口，按 P0/P1/P2 排序并估算覆盖度。
> 标注：**已有** = 可直接用；**部分** = 有但不完整；**缺失** = 没有。覆盖度为按场景加权的主观估算（每个“角色×环节”格子按该角色使用频率加权）。
> 参考竞品：Keepa、CamelCamelCamel（历史价/目标价/降价提醒/浏览器插件）、Prisync、Price2Spy、Omnia、Competera（竞品监控/定价规则/MAP/报表/API）、慢慢买、什么值得买（历史价/到手价/促销日历/值不值得买）、千瓜/蝉妈妈类数据工具（达人/直播带货数据）、卖家精灵（选品/销量/关键词/库存估算）。

## 1. 生命周期 × 现状（v4 时点）

| 环节 | 现有能力 | 状态 | 主要缺口 |
|---|---|---|---|
| 发现 | 920 平台目录、关键词/类目/产业链/语义/以图/AI 搜索、搜索建议 | 已有 | 浏览器插件/书签一键收藏 |
| 采集 | 网页/接口/CSV/内置平台/一键粘贴链接、定时监控、体检 | 部分 | **无头浏览器渲染**（95 个平台需 JS）、代理池、多规格 SKU、库存/上下架、运费/优惠券 |
| 清洗归一 | 置信度、币种字段 | 部分 | **汇率换算**、含税/运费/优惠券**到手价**、单位归一 |
| 同款匹配 | 标题归一化 group_key、手工深度对比 | 部分 | **智能匹配（GTIN/品牌型号/标题向量/图片）**与人工确认 |
| 监控告警 | 涨跌 ≥5% 自动告警（站内） | 部分 | **告警规则**（目标价/跌幅/涨幅/库存/破价）、**通知渠道**（Webhook/企微/飞书/钉钉/Telegram/邮件）、静默期 |
| 分析预测 | 历史统计、线性/移动平均/指数平滑预测、置信度 | 部分 | **促销日历**、季节性、**买入时机建议**、卖家画像 |
| 定价决策 | 成本加成/竞品最低-1%/中位数推荐 | 部分 | **定价规则引擎**（跟价/最低毛利/上下限/MAP）、**利润模拟** |
| 执行 | 无 | 缺失 | 推送调价建议（Webhook 给 ERP）、批量审批 |
| 复盘报表 | CSV 导出商品 | 部分 | **汇总报表**（价格指数/价差/违规/告警）、**定时报告推送** |
| 协作与集成 | REST API + /docs、撤销 | 部分 | **API 令牌与权限**、**审计日志**、**Webhook 事件**、**备份恢复**、多语言界面 |

## 2. 角色 × 关键场景矩阵

| 角色 | 关键场景 | v4 状态 | 优先级 |
|---|---|---|---|
| 电商卖家/品牌方控价 | 竞品跟价、MAP 破价发现与**取证截图**、卖家画像（谁在乱价）、定价规则与利润 | 竞品比价已有；MAP/取证/画像/规则缺失 | P0 |
| 采购员 | 多平台到手价比较（含运费税费汇率）、目标价提醒、库存可得性、报表 | 比价有；到手价/库存/目标价缺失 | P0 |
| 比价消费者 | 历史价、目标价提醒、促销日历、现在买还是等、浏览器一键收藏 | 历史价有；其余缺失 | P0（插件 P1） |
| 虚拟商品/卡网商家 | 面值/折扣率、库存（有货/缺货）、多 SKU 面额、秒级变动告警 | 部分（价格监控有；SKU/库存缺失） | P1 |
| 代购/跨境 | 汇率换算、关税/运费到手价、海外平台 JS 渲染站点 | 缺失 | P0 |
| 本地生活 | 团购/外卖价格（多为 App/JS 渲染）、城市维度 | 缺失（依赖渲染/接口） | P2 |
| 数据分析师 | 导出、价格指数、季节性、API 批量取数 | 导出/API 有；指数/季节性缺失 | P1 |
| 团队管理者 | 多用户角色、审计、定时报告、备份 | 缺失 | P1 |
| 开发者/集成方 | API 令牌、Webhook 事件、OpenAPI 文档、私有 API 接入 | 文档/私有 API 有；令牌/Webhook 缺失 | P0（Webhook）/P1（令牌） |

## 3. 缺口清单与优先级

**P0（本轮必须做）**
1. 无头浏览器渲染采集（Playwright），平台源/一键监控自动回退，并重新体检可用率
2. 汇率换算 + 到手价（运费、税率、优惠券/满减）
3. 库存/上下架监控（从结构化数据读取可售状态，变化告警）
4. 告警规则（目标价、跌幅、涨幅、库存变化、破价）+ 通知渠道（Webhook、企业微信、飞书、钉钉、Telegram、邮件）+ 静默期
5. 智能同款匹配（GTIN/型号、品牌、标题向量、图片相似）+ 人工确认合并
6. 促销日历（618、双11、双12、黑五、网一、Prime Day、年货节等）+ 买入时机建议
7. MAP/最低限价控价：违规列表、取证截图（无头浏览器整页截图）、卖家画像
8. 定价规则引擎 + 利润模拟
9. 汇总报表导出（CSV/HTML）+ 定时报告推送到通知渠道

**P1（尽量做）**
10. API 令牌与角色权限（管理员/编辑/只读）+ 审计日志
11. Webhook 事件（价格变动/告警）给 ERP 等系统
12. 数据备份与恢复
13. 多规格 SKU（结构化数据多 offer 拆分为规格）
14. 代理池（采集轮换代理）
15. 浏览器一键收藏（书签工具，无需安装插件）
16. 季节性（按星期/月份）价格规律

**P2（后续）**
17. 正式浏览器扩展（Chrome/Edge 商店上架）
18. 多语言界面（英文/日文）
19. 本地生活/直播电商/App 内价格（需官方接口或移动端抓包授权）
20. 销量/排名估算（卖家精灵类）、达人带货数据（千瓜类）
21. 自动执行调价（直连各平台卖家后台 API，需各平台授权）

## 4. 覆盖度估算

| 阶段 | 估算覆盖度 | 说明 |
|---|---|---|
| v4 | 约 55% | 发现、比价、历史价强；告警/到手价/控价/规则/协作弱 |
| v5 目标（P0 全部 + 主要 P1） | 约 85–88% | 剩余主要是 P2：App 内价格、销量估算、正式插件、自动执行调价、多语言 |
| 99% 的前提 | — | 需要各平台官方/授权接口（反爬站点无法靠技术手段稳定读取）、移动端数据与卖家后台授权，属于商务与合规问题，不是单纯开发能解决 |
