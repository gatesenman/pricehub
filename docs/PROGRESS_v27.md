# PriceHub v27：安全批量删除与撤销

时间：2026-11-24（Asia/Shanghai，UTC+8）

## 审计依据与实现
撤销令牌原来没有检查工作区、消费时没有检查过期，INSERT OR REPLACE 会覆盖删除后重用 id 的新商品。现令牌绑定工作区+600 秒有效期、互斥消费、事务恢复使用 INSERT，冲突 409 且不覆盖任何行；批删同步保存/删除关联提醒/证据/去重候选，禁止直接删仍有合并页或规格的商品。测试图片/证据目录支持显式隔离。

## 验证
test_v27_safe_undo + test_v18_isolation + test_v22_transactions：6 passed；十轮及 v12–v17 相关汇总：64 passed（45.79s）。令牌跨工作区、过期、id 复用保护、关联行删除/恢复已验证。

## 边界
仅临时数据库和目录；未运行真实外发、未改生产数据；不代表真实业务数据覆盖。
