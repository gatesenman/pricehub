# v12（同款自动去重与合并）进度
时间均为北京时间（UTC+8）。

## 检测与打分（app/domains/dedup）
- 属性抽取（features.py）：NFKC 归一化、去营销词；品牌（中/繁/英/日别名）、型号与系列（iPhone 17e、Galaxy S25…）、容量（GB/TB/克重区分）、颜色、成色（全新 / 福利翻新 / 二手）、条码（GTIN/EAN/UPC/JAN、ASIN，来自字段或 attrs）。
- 打分（service.score_pair）：条码/ASIN 一致 0.99、不同封顶 0.30；否则 0.45×标题语义（多语言向量，无模型回退 TF-IDF）+ 0.20×型号/系列 + 0.10×品牌 + 0.10×容量 + 0.05×颜色 + 0.10×图片（CLIP，无则 phash）；
  归一化标题完全相同且无冲突至少 0.975；冲突封顶：品牌 0.30、容量 0.40、型号 0.50、成色 0.50、颜色 0.60。每条候选带逐项理由（冲突以 ✕ 标出）。
- 范围：同平台不同商品页（same_platform）与跨平台同款（cross_platform）。人工标过“不是同款”的不再提示。

## 复核与合并
- 「分析 → 去重建议」：复核队列（匹配度、类型、两侧商品的平台/价格/价格条数/原链接、理由）、合并（自动选价格多的为主）/ 指定保留哪一个 / 不是同款 / 重新考虑；勾选后批量合并或批量标为不同。
- 合并语义：主商品保留；被合并商品行保留为主商品的“商品页”（merged_into），平台、外部 ID、来源 URL 不变；价格记录移到主商品并在 prices.listing_id 记下来源商品页；
  之后该商品页再采到的价格自动记到主商品；预警规则跟随到主商品；同一商品的其他待处理候选标记为失效。商品列表只显示主商品，详情页新增「商品页」列表。
- 审计与撤销：product_merges 记录每次合并（人工/自动、移动的价格 id、理由、分数）；「合并记录」可撤销，撤销会把该商品页的全部价格（含合并后新采到的）还回去，候选回到待处理。
- 自动合并设置：同平台、跨平台分别开关，阈值只能 0.90–1.00，两者默认都关闭；进入队列的最低匹配度默认 0.70；采集完成后自动检测新商品（默认开）。
- API：/api/dedup/candidates、/scan、/batch、/settings、/merges、/merges/{id}/undo、/candidates/{id}/merge|not_same|reopen、/api/products/{id}/listings。
